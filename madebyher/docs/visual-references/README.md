# Festival border template (2026-09-19)

Real reference image provided by Vishal, saved at
`madebyher/docs/visual-references/festival-border-template.png`.

Style: hand-painted folk-art border (Madhubani/Pichwai-influenced) - peacock, lotus, fish,
Ganesh on an elephant, a Warli-style village scene along the bottom, warm cream/red/green/gold
palette, aged-paper texture. Center is genuinely blank/text-safe - built as a frame, not a
finished graphic.

## How to use this

Prefer this over a from-scratch AI-generated background whenever a MadeByHer post needs a
festival-themed graphic with text/product overlay (Diwali, Dussehra, Chhath, Teej, Rakhi
posts) - it's a real, authentic-looking folk-art frame rather than another generic AI
composition, and it directly matches MadeByHer's actual "real artisan craft" positioning better
than most single-shot AI generations do.

- **When the post needs a text/price/CTA overlay on a bordered background**: use this template
  directly (or regenerate a close variant in this exact style via generate_image, describing it
  precisely - peacock, lotus, fish, Ganesh-and-elephant corner motif, Warli village strip along
  the bottom, cream/red/green/gold palette, aged-paper texture) and composite the actual text
  into the blank center - do not ask the image model to render the text itself, per the
  visual-content-prompts skill's existing rule against in-image text.
- **When the post needs a photo-real product/scene shot** (a specific real product, a UGC-style
  photo): this template doesn't fit, keep using the existing photo-realistic generation approach
  for those.
- This is a MadeByHer-specific asset for now - don't reuse it for RabbitLore or Astra Studio
  without checking it actually fits their brand identity first.
